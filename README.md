# COP-3604 Linux Infrastructure Observability Dashboard Project

This is a starter/template in python to help us get started

## Instalation

### Prerequisites

Python 3.14 or later

### Step-by-Step Guide

1. **Clone the repository**

   ```bash
   git clone https://github.com
   cd project-name
   ```

2. **Create environment**

    ```bash
   python3 -m venv .venv
   source .venv/bin/activate
    ```

3. **Install dependencies**

   ```bash
   pipe install -r requirements.txt
   ```

4. **Run the collectors**

   ```bash
   python3 collectors.py
   ```

5. **Run the Main server**

   ```bash
   streamlit run app.py
   ```
